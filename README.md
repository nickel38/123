# Эмулятор оболочки ОС — вариант 22

Практическая работа №1 по дисциплине «Конфигурационное управление», группа ИКБО-62-25.

Проект реализует консольный эмулятор UNIX-подобной оболочки. Виртуальная файловая система загружается из JSON в память; команды изменяют только состояние текущего сеанса и не перезаписывают исходный JSON.

## Реализовано

- параметры запуска `--vfs`, `--script` и `--help`;
- чтение VFS из JSON (текстовые и base64-файлы), проверка структуры и путей;
- стартовые сценарии с построчным выполнением и остановкой после первой ошибки;
- команды `ls [-a] [путь]`, `cd [путь]`, `pwd`, `date`, `uptime`;
- команда `rm [-rRf] путь...` с защитой корня, текущего каталога и его родителей;
- `conf-dump` для вывода настроек и `exit` для завершения;
- кавычки, пути с пробелами, `.`, `..`, комментарии в сценариях;
- тесты стандартной библиотекой Python.

## Запуск

Требуется Python 3.9+:

```sh
sh run.sh
python3 -m src.main --vfs fixtures/multiple.json --script scripts/startup/stage5.txt
```

По умолчанию используется `fixtures/multiple.json`. Для выхода из интерактивного режима введите `exit` или нажмите Ctrl+D.

## Проверка

```sh
python3 -m unittest discover -s tests -v
sh scripts/check.sh
```

## Содержимое репозитория

- `src/main.py` — точка входа;
- `src/parser.py` — разбор команд и параметров;
- `src/vfs.py` — JSON-VFS и операции с путями;
- `src/shell.py` — команды, сценарии и REPL;
- `fixtures/` — минимальная, обычная и вложенная VFS;
- `scripts/startup/` — демонстрационные сценарии;
- `tests/` — автоматические проверки.
